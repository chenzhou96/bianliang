《汴梁归途》离线试玩版 v4-r6-20260913

一、打开游戏
先完整解压压缩包，不要直接在压缩包预览窗口里运行。
macOS 13 或更新版本：双击“汴梁归途.app”，支持 Apple Silicon 与 Intel。
Windows 11：双击“开始游戏.cmd”，支持 x64 与 ARM64。
游戏会在默认浏览器打开，不需要安装 Node.js，不需要联网。
请保留解压后的完整文件夹，不要单独移动启动文件。
本版没有开发者签名或 Apple 公证。Mac 首次打开若被系统阻止，请在确认来源后，使用“系统设置 → 隐私与安全性 → 仍要打开”。无需关闭系统安全功能。
Windows 可能显示下载文件的安全提示；请核对分发来源。不要在公司或学校受管理的电脑上绕过管理员限制。

二、怎么玩
你带着800文来到汴梁，自选3000文或30000文归航目标。
买卖同价，观察行情低买高卖；合法推广、组织货源或冒险散布风声都能影响价格，但效果不稳定，违法行为可能罚款、拘押。
磨面炊饼、纺织酿造、养鸡置业；接单履约，认识熟客，作出影响故事走向的选择。
时间昼夜连续推进，记得备饭、休息和睡眠。经营没有固定天数上限。

三、保存与退出
进度自动保存在当前浏览器中。请使用同一浏览器，不要使用无痕模式或清除网站数据。
分发版固定地址：http://127.0.0.1:41739 。更换端口、浏览器或电脑不会自动带走存档。
开发版地址不同，因此不会自动读取开发版存档。本版只支持当前存档格式，不迁移旧版。
可使用游戏顶部“导出备份”另存数据；本版没有导入入口，备份不能直接在界面恢复。重要进度请同时妥善保留原浏览器数据。
关闭浏览器后本地服务仍在运行。双击“停止游戏.command”（Mac）或“停止游戏.cmd”（Windows）可完全结束服务，存档保留。
再次双击启动即可继续。更新版本前先停止原版本。

四、常见问题
浏览器没有自动打开：手动访问 http://127.0.0.1:41739 。
端口被占用：先停止原游戏；不要随意更换端口，否则原地址的存档不会显示。
日志：Mac 为 ~/Library/Application Support/BianliangGame/server.log；Windows 为 %LOCALAPPDATA%\BianliangGame\server.log。
包内 manifest.json 记录版本和文件校验值，运行环境来自 Node.js 官方发行版，许可证见各 runtime 目录与 THIRD_PARTY_NOTICES.txt。
验证范围：Apple Silicon Mac 已验证；Intel Mac、Windows x64/ARM64 已核验运行环境与包结构，尚未进行对应系统真机验证。
