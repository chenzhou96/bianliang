## 一、目标与整体节奏

将游戏扩展为以**观察行情、采购原料、学习手艺、生产销售、改善住所**为核心的长期经营游戏。

- 不限经营天数；开局选择 **3000文或30000文归航目标**，两者共用经济规则。
- 保留800文开局。达到目标后可以支付现金归航，也可以继续经营；死亡仍结束本局。
- 取消行动点，以体力、设备容量、加工时间和每日次数约束行动。
- 保留文字叙事、随机事件、本地存档；本轮不加入多城市、雇工、借贷或联网系统。

长期目标的平衡参考为：成熟经营策略约80～120个游戏日能完成30000文目标；这是模拟调参目标，不作为强制期限。

## 二、商品、产业与买卖

### 商品与生产链

在现有8种商品上新增小麦、面粉、盐、柴薪、原麻、麻线、生丝、丝绸、咸蛋，共17种。所有原料和成品都能直接交易，玩家可以自由选择在哪个加工环节介入。

| 产业 | 生产链 | 场地与设备 | 成长方向 |
|---|---|---|---|
| 养鸡 | 粟米喂鸡 → 鸡蛋 | 保留少量随身养鸡；鸡舍扩大规模 | 学习饲养，提高产蛋率 |
| 食品加工 | 小麦 → 面粉 → 炊饼；鸡蛋＋盐 → 咸蛋 | 石磨、灶台、腌缸 | 解锁配方、扩大批量、降低体力成本 |
| 纺织 | 原麻 → 麻线 → 麻布；生丝 → 丝绸 | 纺车、织机 | 从普通布料发展到高价值丝绸 |
| 酿造 | 粟米＋柴薪 → 酒 | 酿缸 | 扩大批量、提高原料利用率 |

- 每类技能设“未入门、入门、熟练、精通”；向师傅付费学习入门，实际生产积累熟练度，再付费进阶。
- 每日最多上课一次，消耗20体力；禁止靠买卖和取消生产刷熟练度。
- 食品和纺织当日完成；咸蛋需2夜、酒需3夜，占用设备，完成后入库。
- 开工一次性扣原料和体力；配方明确显示产量、用时、保质期、设备及技能要求。
- 在制品预留成品仓储空间；投入原料必须尚未过期，成品保质期从完成时起算。
- 技能提升只改善明确的批量、耗材或体力参数，不引入隐藏的随机失败率。

### 经济规则

- 短工初始调整为 **25文／25体力**，重活为 **40文／40体力**，两类合计每天最多两次。
- 打工能补贴基本生活，生产和贸易承担财富增长；成熟生产按单位体力计算的净收益应明显高于打工。
- 市场增加商品分类、持有数量、平均成本、买卖价、涨跌、临期提示和预计卖出盈亏。
- 查看行情、切换分类免费；交易按货物搬运量消耗体力，同日累计计算，拆单不能降低成本。
- 保留买卖差价和每日统一行情，同日往返交易不能稳定套利。
- 原料与成品受关联事件影响，但涨跌幅不完全同步，让直接出售原料和继续加工都有合理时机。
- 成本记录覆盖原料、燃料和饲料；经营账本分别显示贸易利润、生产毛利、学费、设备、住房和生活开支，避免将销售额误当利润。

配方价格、批量和设备成本集中配置，以模拟结果调整；普通行情下基础加工应有正毛利，高价买料仍可能亏损，不保证所有时点开工都赚钱。

## 三、住宅与生存管理

### 住宅发展

采用“临时住宿 → 租住房屋 → 买下院落”的路线。

| 住所 | 支付方式 | 经营作用 |
|---|---|---|
| 街头、庙廊、客栈 | 免费或按夜付费 | 应急落脚，无固定生产设备 |
| 租赁小屋 | 按日付租 | 2个设备位，改善仓储与休息 |
| 租赁院落 | 按日付租 | 4个设备位，可扩建鸡舍 |
| 自有小院 | 一次购买 | 6个设备位，无租金，有维护费 |
| 自有大宅 | 一次购买 | 8个设备位，更大仓储与更好恢复 |

- 每台加工设备和鸡舍各占一个设备位；玩家需要在产业专精与多线经营之间取舍。
- 住宅页面集中显示住宿费用、恢复效果、仓储、养殖容量、设备和升级条件。
- 搬家保留兼容设备；容量不足时先出售货物或拆卸设备，不自动销毁资产。
- 在制设备不能拆卸；可明确选择放弃该批生产，投入原料不返还。
- 设备和产权支持按固定折价出售，租金不返还，禁止搬家或转卖刷钱。
- 租金在夜间预览中列出；付不起时允许退租。遗留设备封存、生产暂停，普通货物允许卖出或处理后再搬出。
- 自有住宅维护费付不起时暂时停用恢复加成及新开工，不产生负现金或无法结束当天的死局。

### 体力与健康

- 体力上限按健康分档：健康≥70为100，40～69为80，1～39为60。
- 低于40健康不能重活或进行高强度加工；交易和轻量经营仍可进行。
- 生产、交易、学习、打听消息及事件选择使用统一体力校验，按钮提前显示消耗与不能执行的原因。
- 白天休息一次恢复25体力，加餐一次最多恢复15体力；不允许循环恢复形成无限劳动。
- 夜间由住宿和饮食共同决定恢复量，取消“住客栈或租屋直接回满”。
- 当日体力降至10以下触发劳累，额外损失健康；确认将跨过危险线的操作前给出明确提示。
- 保留风寒，增加付费就医和消耗药材调养；治疗每日一次，分别提供快速治疗和较慢恢复。
- 不增加独立饥饿条，以每日饮食、健康、体力和异常状态承载生存压力。
- 免费住宿和不吃饭始终是可选项，但清楚展示代价；夜间将食物、饲料、租金和恢复效果统一预览，确认后一次结算。

## 四、茶馆情报重点扩展

既增加内容量，也增加判断方式，避免只是替换商品名称，减少长期经营中的审美疲劳。

- **首批至少120条情报模板**：覆盖粮食、食品、养殖、纺织、酿造、药材、住宅及市井生活；每条提供2～3种叙述变体。
- **消息有不同出处**：船工、行商、伙计、织娘、酒坊学徒、牙人等，各有熟悉领域与口吻；同一个人也不一定次次可靠。
- **内容不只预测涨跌**：增加原料供应、成品需求、生产经验、拜师线索、住房消息及人物后续。生活闲谈与可操作情报明确区分，避免玩家把每句话都当任务。
- **真假有迹可循**：消息可能准确、夸大、延期、过时或落空，通过出处、细节和交叉印证判断，不直接公布后台真相。
- **支持追问与回访**：玩家可付出少量钱或体力追问；后续能听到兑现、辟谣和人物回应，让消息有前因后果。
- **按语义去重**：同一具体情报20天内不重复，同一故事骨架7天内不重复；换措辞仍算重复。每次优先提供未听过且与当前经营相关的内容，同时保留其他产业消息。
- **情报必须对应真实规则**：涉及行情、配方、老师或房源的消息连接实际事件和功能；刷新、重复进入茶馆不能重抽消息。
- 内容采用手工模板与规则组合，不增加在线AI调用费用。

## 五、分类集中与桌面一屏布局

以**浏览器可用区域1536×864及以上、100%页面缩放**为无滚动验收标准，不以显示器物理尺寸判断。

- 顶部常驻：日期、天气、现金、归航进度、健康、体力和重要异常。
- 主工作区设六类：**市场、生产、住宅、人物、情报、账本**。
- 市场内部集中交易和库存；生产内部集中设备、配方和队列；人物内部集中技能、饮食、休养和治疗。
- 侧栏显示所选项目详情、费用预览及操作按钮；底部固定“安排今晚”和最新结果。
- 所有长列表使用分类、筛选与分页；剧情、事件、夜间安排和结局使用固定工作区及分步页面，完整文本可以翻页查看。
- 页面及面板均不依赖上下、左右滚动；不能用裁切文字、隐藏按钮或过小字号实现一屏。
- 正文至少14px。较小窗口和手机采用独立自适应布局，允许纵向滚动，保证功能可用。

## 六、实现顺序与验收

### 实现顺序与接口变化

1. **规则与状态**：扩展商品配置；加入开局目标、技能、住宅、设备、生产队列和每日次数；移除行动点与第30日强制结算。
2. **经营引擎**：在统一操作入口增加学习、开工、住房交易、设备管理、加餐和治疗；所有失败操作保持资源及随机状态不变。
3. **长期运行与茶馆**：行情事件持续向未来补充；一次性故事保留完成记录，可重复日常事件采用冷却；完成情报模板、来源、追问回访及语义去重。近期日志有上限，累计账目单独保存。
4. **界面与接入**：完成分类工作区，统一使用引擎提供的费用和限制预览；同步更新现有WebMCP操作和公开状态，不公开隐藏事件真相。
5. **存档与说明**：新规则使用独立版本和存储键。默认不迁移旧局，保留旧存档并提供导出；新开局不得静默覆盖旧数据。更新玩法说明和测试报告。

### 验收重点

- 每条产业链完成“采购—学习—安装—开工—过夜—销售”，刷新后进度和成本一致。
- 覆盖缺钱、缺料、体力不足、设备占用、满仓、临期原料、重复提交和取消操作。
- 覆盖搬家容量不足、退租、设备封存、产权出售及断供后的恢复。
- 检查健康阈值、劳累、治疗次数及夜间多项资源共享，保证没有无限恢复或重复生产漏洞。
- 在至少100组相同种子上比较劳动、贸易、养鸡、食品、纺织、酿造及混合策略；玩家策略只能读取已知信息。
- 劳动路线的财富增长明显慢于有效经营；每条产业都有可盈利的发展路径，不能仅靠重复买卖或搬家获利。
- 连续经营100天，统计茶馆内容重复率、题材分布和线索兑现情况；人工连读20次茶馆内容，检查人物口吻和情境差异。
- 运行1000游戏日稳定性测试，验证持续事件、存档体积和账目一致性。
- 在1536×864、1920×900、1920×1080可用区域检查各分类、最长事件、错误提示、夜间安排和结局，页面与面板均无滚动、无遮挡。
- 完成规则测试、类型检查、构建及浏览器流程验收后交付。
