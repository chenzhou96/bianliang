# 首日生活体验更新

依据：玩家在租下300文小屋、买三只鸡、茶馆听消息后，找不到下一步行动；营业时辰、住宅操作与跨日期限不清晰。

## 已落实

- 新增“街巷”工作区与常驻“此刻能做什么 · 招工告示”入口。短工、重活迁至招工告示，人物保留身体照料与学艺。
- 街巷展示当前可执行的短工、闲置现货收购及饭食鸡群安排。现货建议用公开收购信息、可用余量和实际操作预览判断，不承诺利润；没有可交付现货时给市场入口。
- 时辰表按当前时刻排列未来24小时的城市变化；公开各场所营业时间、劳动最迟开工时间。行动显示今天／明天几点完成。夜市开张前可等夜市，晚上可等次日早市，沿用既有时间风险提示。
- 今日打算可选三件事，作为本地界面备忘；不消耗时间、不自动执行、不保证未来价格。办妥手动取消，跨日另起一页。
- 住宅按饭食、鸡群、歇息分区。自动喂鸡使用复选框，说明开启状态、下次日期、只用已有粟米且缺粮不自动采购。
- 吃饭、产蛋检查、自动喂鸡、首次房费、睡醒、订单截止使用明确日期；不再让玩家猜“06:00”属于哪一天。
- 操作按钮统一顶部对齐，预览与错误信息独立在下方。生活输入与按钮按列排列；手机单列。街巷整列滚动，避免每张小卡片独立滚动。
- 公开接口同步提供城市时辰表。未改经济数值、结算机制或存档结构。
