# 统一牌价与主动影响行情

2026-09-13。用户决定：普通市场买卖统一价格，并提供合法及违法、效果不稳定的主动行情玩法。此文覆盖旧方案的固定买卖差价约定。

## 已实现的规则

- 普通市场每种商品只有一个牌价，初始化、每日06:00议价、成交锁价、持仓估值和走势图一致。运输费、时间、体力、库存成本及腐坏仍照常结算；小数交易按原有整文收付取整，不能通过拆单制造收益。
- 删除旧首日卖价配置。内部买/卖字段代表同一牌价，当前存档拒绝不相等的现价。原粮商熟客改为合法影响粟米行情的奔走费减5文，不产生买入后即刻转售的折扣套利。
- 货盘是每日有限、整批采购的5—15%批发折价，保留现货收购的限量合同价格。普通/高风险订单相对统一牌价上浮10%/15%，替代旧卖价上浮25%/30%，避免取消价差后重复抬高订单收益。它们属于特定交易机会，不是普通市场的第二张报价单；货盘买过不能再领。
- 在市场所选商品详情展开“主动影响行情”。所有手段共用48小时冷却，自结算完成起算；影响仅到下次06:00议价，不叠加、不承诺跟进成功。价格仍受基础价50%—200%边界限制，整数取整可能使小幅变化不显著。

| 手段 | 费用 / 耗时 / 体力 | 随机结果 |
| --- | --- | --- |
| 招徕买家，合法 | 30文 / 60分钟 / 8 | 60%上涨5—15%，20%不变，20%反跌5% |
| 联络外埠来货，合法 | 40文 / 90分钟 / 10 | 60%下跌5—15%，20%不变，20%反涨5%；买货另付货款 |
| 散布紧缺消息，违法 | 25文 / 45分钟 / 5 | 45%上涨15—30%，20%反跌10%，35%查获 |

查获时不改变牌价，罚款为150文加扣除奔走费后剩余现金的20%，至多扣光现金；声望至多减少3，拘押12小时。罚款与奔走费独立累计并出现在经营概览，现金收支按实际扣款入账，不混进已售商品毛利。

拘押期间只能查看页面、已知故事并选择“服满拘押”，不能交易、等待、睡眠、交付、放弃约定或归航绕过。服满会推进真实12小时，疲劳、房费、腐坏、订单与故事期限继续结算，结束后回到同一经营界面。拘押状态随存档保存。

## 分支故事

新增茶馆买卖故事“一张茶单，两种生意”：

- 招徕茶客后，限时交付真实炊饼，兑现茶席报酬并认识行商。
- 联络来货后，等待船主回信、核对实货，建立摆渡人关系。
- 假消息未查获时，玩家自行决定是否到市场交易，并可更正消息或断开掮客来往；不自动替玩家卖货或发固定“操盘奖励”。
- 查获后进入市司章节，先服满拘押，再面对茶商或认罚收束。处罚不随更正、结局或读档撤销。
- 开篇保留免费拒绝，合法茶席有期限和缺料禁用。与既有故事共用三条活动故事上限。
