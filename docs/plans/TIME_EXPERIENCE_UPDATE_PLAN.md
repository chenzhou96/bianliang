# 《汴梁归途》时间与日常经营体验更新方案

本方案承接本轮时间体验审查与同类游戏比较。保留连续时间、行动推进、浏览和离线不走时、无限天数经营；不增加地图移动、行动点、员工排班或强制夜间页面。

## 1. 目标、范围与参考

本轮交付疲劳与恢复、一次收工到明早、营业收尾、目标等待和生活界面。时段特色、新故事、多商品合并采购属于后续方向，不作为本轮验收条件。

- [星露谷物语](https://wiki.stardewvalley.net/Day_Cycle)：主动结束一天、稳定次日起点；不照搬凌晨强制昏倒。
- [Travellers Rest](https://travellersrest.wiki.gg/wiki/Tavern_Management)：停止受理与完成现有业务分开。
- [Graveyard Keeper](https://graveyardkeeper.fandom.com/wiki/Stone_garden)：恢复身体和等待目标是不同需求。
- [潜水员戴夫](https://store.steampowered.com/app/1868140/DAVE_THE_DIVER/)与[80 Days](https://www.inklestudios.com/2014/04/15/so-what-is-eighty-days)：时段特色和行动叙事留作后续内容。

## 2. 规则

### 疲劳与恢复

- 即时劳动消耗体力；正常清醒不降低体力上限，健康分档保留。
- 疲劳负荷以分钟记录：清醒+1/分钟，睡眠−2/分钟，最低0；取消睡满4小时直接清零。
- 负荷不足14小时精神充足，14—16小时有些疲惫，16—20小时困倦，20小时以上十分困倦。14小时以前不提醒睡眠。
- 超过16小时才每清醒小时累计0.5小时睡眠债；每睡眠小时减少1小时，范围0—12。债务前2小时不扣上限，超出每小时−3，最低上限30。
- 超过18小时，体力倍率每小时+0.1，最多2倍；超过24小时每清醒小时−2健康。取消22:00、02:00固定身体惩罚。
- 住宿、昼夜恢复效率、卧房与免费住宿风险保留；短休60分钟最多+20体力，不消除负荷与睡眠债。恢复显示实际增量与最终值；无净收益短休禁用并给等待入口。

### 营业收尾

交易/货盘/收购/契约交货拆成10分钟受理和剩余搬运。10分钟手续须在相应营业窗口内完成，脚夫也按此接活，搬运允许跨关门。明确交货截止仍按全部运输完成判定，恰好截止允许。非运输活动仍须全部在营业内完成。

锁价、开始预留、途中腐坏、死亡释放与完成后收入维持。受限交易提供可行数量、各搬运方式完成时刻和费用，须由玩家选择，禁止自动切换付费服务。

## 3. 日常操作

### 收工到下一08:00

主要入口为“今日收工”，可勾选先吃所选主餐，已吃则省略。无静默替换饭食或住宿，无自动购买。用餐后最后最多8小时安排睡眠，之前居家闲处；闲处不恢复且累积疲劳。剩余睡眠不足8小时提醒，不足1小时禁用并提供等到08:00。整个安排最多24小时；自选1—10小时睡眠仍可用。

客栈实际入睡时收费一次。整套预校验，无效安排无副作用；逐分钟结算生产、腐坏、费用、饮食、喂养、截止与死亡。预览分段时刻、真实恢复、开支和风险；跨订单截止、缺餐或住房停用增加一次确认。普通收工直接执行。醒后摘要优先显示成果、净收支、异常，可收起。复合安排记一次操作，各费用账目保留。

### 目标等待

市场/街巷提供开市和夜市目标，生产队列提供完工目标，订单按当前运输方式倒推最晚可交货开始时刻。引擎根据目标类型/关联ID重新计算，拒绝过期、超过24小时、停产及缺乏货物资源的交货目标。等待后须仍可交货。跨已知订单截止优先提供较早交货目标，原目标可明确确认。等待不恢复、不触发额外交互遭遇。等待30分钟放在次级菜单。

### 界面

住宅首屏排列主餐、短休、收工；无鸡隐藏喂养区。自选睡眠与鸡群放折叠区。饭食/住宿偏好按本局记忆，住所失效说明并要求重新选择。顶部显示时刻、疲劳、最近营业节点；公式放说明。时长使用小时/分钟，跨日明确今天/明天。住宅底栏提供当前安排收工入口。

## 4. 实现与版本

共享引擎、预览、UI与WebMCP统一规则。时钟使用fatigueMinutes与新定义的sleepDebt；行动增加closeDay与waitUntil，预览增加segments、受理时长和提前停止目标。反馈键区分嵌套目标。

使用版本4、规则4.0-time-experience和bianliang-save-v4。不迁移、不加载旧版本，不删除或覆盖v1/v2/v3键。新字段严格校验。保留独立更新前模拟副本与结果，再验证更新后结果；生成证据不提交。
