# 美术版界面实施

目标：沿用现有经营规则、v4 存档与三栏常驻信息，将文字工作区升级为宋画市井场景与物件操作界面。

## 验收清单

- [x] 开场使用汴河主视觉；街巷有带名称的场景入口。
- [x] 市场支持商品插画与清晰的价格比较、买卖及时间消耗。
- [x] 生产使用设备插画，展示实际拥有、安装与生产状态。
- [x] 住宅按真实住房与设施展示生活空间，避免装饰鸡群冒充库存。
- [x] 茶馆使用场景与对话式消息；人物、账本、订单沿用统一视觉规范。
- [x] 昼夜表现与游戏时辰一致，动态可关闭，保留文字标签与键盘操作。
- [x] 原始素材保存在 design/art-assets，网页使用 public/art 下压缩派生图。
- [x] 1536×864、1920×900、1920×1080 桌面及 390×844 移动检查；长内容、满库存、各工作区与主要经营流程验证。
- [x] typecheck、lint、规则测试、build 与浏览器检查通过；更新 TEST_REPORT.md。

既有未提交改动属于当前开发基线，不回退或覆盖。美术化不改变规则、时间、价格、存档和 WebMCP 的已知信息边界。
