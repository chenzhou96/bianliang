# 汴梁归途 · 长期经营版

八百文开局，在汴梁观察行情、采购原料、拜师学艺、生产销售、改善住所。开局可选 **3,000 文**或 **30,000 文**归航目标；没有经营天数上限，达标后可以支付现金归航，也可以继续经营。健康归零即结束。

## 开始玩

1. Windows 可双击本目录的 **开始游戏.cmd**；macOS 在项目目录执行 `npm start`（首次先安装依赖并构建，见下方）。
2. 浏览器打开 **http://127.0.0.1:4173/**，选择归航目标并开始。
3. 再次打开时可继续 v2 存档；v1 旧存档保留，不会被静默迁移或覆盖。

服务只监听本机地址，存档只在当前浏览器。启动需要 Node.js 22.13 或更新版本。

## 玩法概要

- 没有行动点。短工、重活合计每天最多两次；上课、休息、加餐、治疗也各有每日次数限制。
- 17 种商品可自由交易：粟米、小麦、面粉、盐、柴薪、原麻、麻线、生丝、丝绸、炊饼、母鸡、鸡蛋、咸蛋、麻布、茶叶、酒和药材。
- 生产链覆盖养鸡、食品加工、纺织和酿造。生产前要拜师并安装设备；当日成品立即入库，咸蛋需 2 夜、酒需 3 夜。设备占用住所设备位，在制品预留成品仓储空间。
- 住所路线为街头 → 租赁小屋 → 租赁院落 → 自有小院 → 自有大宅。租金/维护费在夜间统一预览；无力支付租金会退租到街头，设备和货物不会自动消失。
- 市场交易按搬运量消耗体力，同日累计；价格每日统一更新，保留买卖差价。账本区分采购现金支出、已售成本和毛利，并分别列出学费、设备、住房、生活、饲料和医疗；饲料投入已分摊到鸡蛋成本，不能再从生产毛利重复扣除。
- 茶馆提供120条具体市井消息及行情传闻，不再混入经营常识。消息可追问、到期回访，结果随本局保存；语义20日去重，每次最多一条行情，同类行情间隔至少7日。
- 限时供货订单、熟客故事、阶段目标和公开节庆提供长期经营机会；高风险订单需冻结保证金，违约损失独立记账。

## 桌面操作与存档

- 采用紧凑A布局：顶部状态、左侧完整资产清单、右侧最近50次经营记录常驻。状态和资产全部展开，不折叠、不滚动。
- 主页面不滚动；市场、生产、情报、订单等长列表和详情在工作区内部滚动，完整记录在右栏内部滚动，不再翻页。
- 白天直接买卖、补齐原料和开工，无须进入或离开市场；生产后可直接跳转出售成品。采购、生产、休息和打工均显示实际资源变化。
- 1536×864、1920×900、1920×1080，100%缩放已验收；夜间入口位置固定，不通过裁切正文实现一屏。
- 情报必须先追问出处，再到期回访；未取得的核对内容不会通过页面或可选WebMCP提前显示。
- 跨过劳累线、放弃在制品、出售资产或退租会先确认。所有新局入口均保护已有存档。
- 顶部可导出存档。修复前的v2账本曾重复计成本，因此升级后分类账从继续游戏当日重新记账，现金、库存和进度保留；首次保存会留下一份修复前原始备份。原来的无效占位情报不继续展示，备份保留原记录。
- 三万文目标属于长期经营，策略节奏不同。最新实测数据与边界见 `TEST_REPORT.md`。
