# 汴梁归途 · 连续时间经营版

八百文开局，在汴梁买卖货物、打工、学艺、生产、养鸡与安家。可选 **3,000文**或 **30,000文**归航目标；没有经营天数上限，达标后自行决定何时归航。健康归零则旅程结束。

界面已接入宋画淡彩场景、商品与设备插画，以及随住房等级变化的生活空间。原图和提示词见 [美术素材库](design/art-assets/README.md)，交付范围见 [美术版实施清单](docs/plans/ART_INTERFACE_PLAN.md)。

## 启动

需要 Node.js 22.13 或更新版本。首次安装与构建：

```sh
npm ci
npm run build
npm start
```

浏览器打开 [本机游戏](http://127.0.0.1:4173/)。Windows 完成安装构建后也可双击根目录的 `开始游戏.cmd`，使用 `停止游戏.cmd` 关闭服务。开发时运行 `npm run dev`，同样使用4173端口；不要同时启动两个服务。

## 第一天怎么玩

- 从顶部“此刻能做什么 · 招工告示”进入街巷，找短工、查看现货收购，或记下最多三件“今日打算”。
- 查看时辰表，提前安排市场、茶馆、熟客和夜市。每次操作会显示耗时、完成时刻、体力与风险；切换页面和离线不消耗时间。
- 住宅的“生活”按饭食、鸡群、歇息分区。主餐期限和醒来时刻明确标注今天或明天。
- 自动喂鸡须主动开启，每天05:30只使用已有粟米，缺粮不会自动采购；06:00检查饮食、房费及产蛋，并更新行情。养鸡需要备料和等待。
- 做事消耗时间与体力。打工和短暂休息没有每日次数上限，但打工要在营业时段内完成；学习、治疗、加餐保留周期限制。休息不能代替睡眠，熬夜越久代价越大。

## 经营内容

- 17种商品、食品／纺织／酿造生产链与连续加工队列。生产前准备技能、设备、原料及仓储空间。
- 市场提供价格走势、持仓成本、保本价、限量收购、货盘及夜市尾货。可自行搬运、使用手推车或雇脚夫；收益须计入成本与运输。
- 住所从租赁到自有，支持仓储、凉储、会客和卧房设施；可封存、重装及出售设施，房费按清晨时点收取。
- 茶馆消息、供货订单、六位熟客、家宴与商人成长纪念物提供长期目标。只显示玩家已经获得的信息，不提前揭示随机结果。
- 桌面保持顶部状态、左右资产与记录，长内容在区域内滚动；手机采用单列阅读。白天与夜晚自然衔接，没有独立晚间页面。

## 存档

进度保存在当前浏览器的 `bianliang-save-v4`，可从顶部导出。v1/v2/v3旧存档保留原键并允许导出，**不迁移、不兼容旧进度**。新局替换当前进度前有确认；保存失败时会提示。浏览器之间不会自动同步。

## 开发与验证

| 命令                                 | 用途                                            |
| ------------------------------------ | ----------------------------------------------- |
| `npm run dev`                        | 本机开发服务                                    |
| `npm run typecheck` / `npm run lint` | 类型与静态检查                                  |
| `npm test`                           | 规则与公开接口回归                              |
| `npm run build` / `npm start`        | 生产构建与本机启动                              |
| `npm run test:browser`               | 六个真实Chrome浏览器脚本；需先启动本机服务      |
| `npm run simulate`                   | 连续时间策略模拟，默认七种策略、各30种子、100日 |
| `npm run test:content`               | 情报内容抽样与去重检查                          |
| `npm run format`                     | 格式化                                          |

最近验证包含113项规则／接口测试，桌面1536×864、1920×900、1920×1080与手机390×844。具体结果、模拟边界与历史证据见 [TEST_REPORT.md](TEST_REPORT.md)，不以测试数量替代可玩性评价。旧策略入口 `npm run simulate:legacy` 仅供历史对照，当前经济验收使用连续时间模拟。

### v4时间与日常安排

正常活动不会一醒来就欠觉。体力用于劳动，睡眠消除疲劳负荷；持续清醒超过16小时才开始积累睡眠债。主餐、短休、今日收工位于住宅生活页首屏；收工可包含饭食，一次安排到下一08:00，按实际睡眠恢复。自选睡眠与鸡群管理在折叠区。

市场10分钟手续在营业内办妥后，可继续搬运至关门后；订单明确截止仍须准时完成运输。街巷/市场、生产队列和订单提供目标等待，等待不恢复体力，风险先预览。详细规则与验收见[更新方案](docs/plans/TIME_EXPERIENCE_UPDATE_PLAN.md)。
