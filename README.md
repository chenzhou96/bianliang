# 汴梁归途 · 文字 Demo

八百文开局，三十日内积攒三千文，回到现代。可在本机浏览器玩完整一局；没有账号、云存档或 AI 接口费用。

## 开始玩

1. 双击本目录的 **开始游戏.cmd**。
2. 浏览器打开 **http://127.0.0.1:4173/**，点击“走进汴梁”。
3. 再次打开时选择“继续第几日的旅程”。重开前会确认覆盖存档。

游戏服务在后台运行。玩完可双击 **停止游戏.cmd**，停止服务不会删除浏览器存档。

启动需要 Node.js 22.13 或更新版本；启动器优先寻找本机 Codex 提供的 Node，其次寻找常规安装。本次交付已包含编译好的 `dist/client`，日常游玩不必安装依赖，也不需要联网。移动到其他电脑时需要先安装 Node。

存档属于当前浏览器及当前地址。`localhost` 与 `127.0.0.1`、不同端口和不同浏览器不共享存档。首次测试建议始终使用上面的地址。只有一个当前存档位；请勿在多个标签页同时推进同一局。

## 玩法

- 每天两次行动。看行情免费；进入市场消耗一次行动，本次访问可连续交易。
- 去茶馆花8文听消息，结合来源与线索判断；并非所有传闻都会兑现。
- 短工收入60文，消耗25体力。重活收入 **75文**，消耗40体力，要求健康至少40。
- 每夜选晚饭、住宿、喂几只鸡。提交前统一检查资源，不能花一份粮同时吃饭和喂鸡。
- 每只鸡每夜吃0.2份粟米，70%概率产蛋。连续三夜断粮死亡。鸡舍可养12只，产蛋率80%。
- 租房300文住到本局结束；鸡舍240文。租屋可省下夜间住宿费并扩大库存。
- 炊饼在获得后的第3夜末到期，鸡蛋在第5夜末到期；到期当夜仍可先食用。夜里新产的蛋次日使用。
- **归航只认现金。** 钱压在货物和母鸡里时，先去市场出售。达到3000文后可直接归航，也可继续经营；第30夜是最后机会。
- 健康归零即死亡。现金归零不直接结束，还可以劳动、歇脚和选择免费住宿。

### 随机遭遇

共有8个个人事件家族、24个具体情境，每个情境有两套叙述。一个标题可能对应真求助、骗局或另有条件的交易，不能只背事件名称。每个版本的关键选择至少有两种可能结果，费用提前说明，回报不保证。

查问花5文，可得到与本次事实一致的额外线索。查看、刷新、关闭后再打开都不会重抽。个人事件每日最多一个，同一家族冷却4日，同一具体情境一局不重复。两条人情事件链可能送来回礼、工作、再次求助，也可能没有后续。

世界行情有6个事件家族：水运受阻、茶船抵达、征粮、庙会、药铺收购、粮船抵埠。每次发生时间、规模、持续日数及是否落空都有变化。新手开局只固定茶馆引导，不固定消息真假与首夜产蛋。

### 与原计划的数值调整

重活从90文调整到75文，其他主要初始数值保留。首轮模拟中原报酬让纯劳动在第16日归航；调整后约第20日。当前400局基准模拟中，四种谨慎策略平均第20～24日归航，详见 `TEST_REPORT.md`。模拟策略会在达标前出售资产，不代表普通玩家必然成功。

## 开发与验证

源码为 Sites 标准脚手架上的 React + TypeScript，事件文案与数值分离。仅导出静态页面，本机服务只负责发送这些页面文件，不接收游戏状态。

```text
npm ci
npm run dev
npm run typecheck
npm test
npm run simulate
npm run build
npm start
```

测试脚本直接运行 TypeScript，推荐 Node.js 24。Node.js 22 运行测试时需要支持内建类型擦除的较新小版本。日常启动仅使用普通 JavaScript。

| 位置 | 内容 |
|---|---|
| `lib/game/config.ts` | 初始报价、产蛋率、工资、容量、归航门槛 |
| `lib/game/content.ts` | 个人事件家族、情境、线索、结果权重 |
| `lib/game/engine.ts` | 统一操作入口、日结、交易、行情、存档校验 |
| `lib/game/types.ts` | 状态与事件类型 |
| `app/page.tsx`、`app/globals.css` | 游戏页面和排版 |
| `tests/` | 规则测试、400局模拟、浏览器验收脚本与结果 |
| `scripts/serve.mjs` | 仅监听127.0.0.1的本机静态服务 |

浏览器验收脚本使用 Playwright 的 `chromium` 与本机 Chrome，不使用日常浏览器配置。设置 `PLAYWRIGHT_MODULE` 为可用的 `playwright-core` 包路径后运行 `node tests/browser.mjs`，可用 `GAME_URL` 指定地址。

Windows 上的 Node 24 与当前 Vinext 在预渲染后立即退出，可能触发 `UV_HANDLE_CLOSING`。`scripts/build-shutdown.mjs` 仅将成功退出延后1秒，等待后台关闭回调完成，不忽略任何失败退出码。没有修改依赖源码。

## 已知限制

- 30～45分钟是目标体验长度；已完成自动策略与浏览器完整流程测试，**尚未有真人计时试玩验证**。
- 事件是手工编写的有限内容与随机分支，不会无限生成新故事。长期游玩仍可能学会识别线索。
- 当前为单机试玩，存档可被使用者从浏览器开发工具修改；不设计联机排行榜或防作弊。
- 住房与鸡舍不可出售；母鸡可出售。饲料成本按实际消耗批次记录，初始赠送粮食成本为零。自产蛋收入与普通买卖利润分开统计。
- 可选 WebMCP 接口只返回玩家已知信息，在不支持该接口的浏览器中自动跳过。真实浏览器原生注册尚未验证，页面按钮不依赖它。
- 日期采用“第几日”计时，人物、价格与事件为游戏设定，不是北宋史料模拟。
